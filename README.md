# Prime Game Hub — концепт сайта

Концепт-сайт сети компьютерных клубов **Prime Game Hub** (Астана, 16 клубов).

- Сайт: https://prime-game-hub-astana.vercel.app
- Закрыт от поисковиков (`noindex, nofollow`), в подвале помечен как концепт.
- Зачем: 16 клубов, 5 362 отзыва и 11 422 оценки в 2ГИС, но сайта нет. В карточках только телефон, Telegram и Instagram.

## Что внутри
- Прелоадер в виде загрузки системы, плавный скролл (Lenis), сцены GSAP ScrollTrigger, лёгкие линии развёртки поверх экрана.
- Первый экран: неоновая сетка-пол едет навстречу и наклоняется за курсором, рамка HUD, заголовок собирается из случайных символов.
- Радар со сканирующим лучом и 16 точками по координатам 2ГИС. Рядом список клубов как список серверов: район, рейтинг, «открыто круглосуточно», маршрут. Есть фильтр по районам.
- «Минимальный пинг»: геолокация сортирует клубы по расстоянию, рисует полоски сигнала и ставит вас на радар.
- «Лут»: что внутри, словами игроков, карточками-ачивками с полосой опыта.
- Мини-игра на реакцию: 5 попыток, среднее время и звание. Рекорд хранится только в этом браузере.
- Отзывы в виде терминала, контакты, сборщик сообщения для брони: копирует текст и открывает Prime App в Telegram.
